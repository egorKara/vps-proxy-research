# VPS & Proxy Research

[Сайт](https://egorkara.github.io/vps-proxy-research/) помогает выбрать один недорогой европейский VPS с оплатой из России. Текущий приоритет установлен 24 ноября 2026 года. Основа выбора — публичные условия провайдеров, источники, дата проверки и существенные ограничения.

## Страницы и данные

- `/` и `/tables/` — текущий выбор одиночных серверов из `src/data/vps_single.json`: карточки, цена, оплата из РФ, ограничения и первоисточники.
- `/tables/#archive` — закрытый по умолчанию архив 28 предложений, проверенных 3 сентября 2026 года. Исходный `src/data/vps_eu.json` сохранён.
- `/vps-eu/` — первоначальный исследовательский документ с сохранённой датой и ссылкой к текущему выбору.
- `/pairs/` и `/pairs/<id>/` — прежнее исследование пар VPS. Его данные, история инцидентов и собственные критерии сохранены.
- `/archive/` и `/proxy-us/` — прежние материалы проекта.

Приём российских карт или СБП подтверждается только соответствующим источником провайдера. Это не означает успешного пробного платежа. Наличие, окончательная цена в корзине и работа конкретного сервера не выводятся из одного факта доступности сайта.

## Локальная работа

Требуется Node.js 22.12 или новее.

```bash
npm ci
npm run dev
```

Перед публикацией:

```bash
npm run validate
npm test
npm run build
```

## Обновление и публикация

`src/data/vps_single.json` обновляется по фактически проверенным публичным источникам. Исторические даты не заменяются датой сборки. Ежедневный `refresh.yml` продолжает сбор истории инцидентов для прежнего исследования пар; цены и способы оплаты одиночных VPS он не перепроверяет.

Публикация выполняется штатным `.github/workflows/deploy.yml` при изменении `main`. Результат проверяется по запуску GitHub Actions и опубликованной странице. Подробности и границы автосбора — в [docs/OPERATIONS.md](docs/OPERATIONS.md).

В `astro.config.mjs` сохранён `base: '/vps-proxy-research'`; внутренние ссылки строятся относительно `import.meta.env.BASE_URL`.
